# 模型情报月报（公开站点）

站点地址：[https://leo-liz.github.io/model-intelligence-monthly/](https://leo-liz.github.io/model-intelligence-monthly/)

本仓库只保存经过本地校验的公开静态产物，用于 GitHub Pages 发布。`site/` 包含最新首页、公开月报 JSON、按月不可变历史和社交预览图；Excel、研究台账、内部协作材料和凭据不进入本仓库。

每月更新由本地任务完成研究与构建。通过完整校验后，同步新的 `site/` 内容并更新 `main`；GitHub Actions 核对必需文件后发布。首页展示当前成功月报或同月补充样本；有更新月份的月报时优先展示新月报。`site/reports/YYYY-MM/` 保存历史月报，`site/reports/samples/YYYY-MM-DD/` 保存补充样本，`site/reports/index.json` 提供索引。Actions 和 Pages 不负责检索或判断模型信息。

历史 Excel 登记的功能与模型关系不等于当前真实调用；本次调用样本是一段时间的工具流水，不是完整业务任务或结算账单。报告中的候选方向不代表已经完成生产切换验证。

当前首页新增 2026-11-17 样本修订版，模型信息观察窗口为 2026-10-19 至 2026-11-17。业务数据仅覆盖北京时间 2026-11-12 15:00–18:00：816,481 条调用、估算成本 5,680.97347604 元。只公开经授权的脱敏汇总，不外推整月调用、成本或节省。完整的 2026-11-01 月报仍可从历史入口直接访问，原页面和数据不变。

八、九、十月页面和数据仍可直接访问。十月与十一月候选纠正前的页面、数据和纠正说明保留在各自 `versions/` 下；版本索引指明当前版本、归档版本和替代关系。退出观察窗口不等于下线，候选移除不等于生产停用，登记变化不等于真实调用变化。

发布前运行 `node verify-deployment.mjs`。工作流只验证并上传 `site/`；部署完成还须核对精确提交对应的 Actions 结果，并禁用缓存回读全部公开资源。本地验收通过或推送成功均不等于线上验收完成。
